# GSE125583 raw validation data

`raw_counts.tsv` is the public count matrix obtained from GEO accession
GSE125583. The associated download and preparation notebooks are under
`scripts/04_external_validation/GSE125583/`.

Only the 200 AD/control samples used for validation are represented in
`data/metadata/GSE125583/metadata_200samples.csv`; the broader downloaded GEO
metadata is retained as `metadata_GSE125583.csv`.
