# GSE203206 metadata

## Source

`GSE203206_Subramaniam.ADRC_brain.metadata.tsv` is the decompressed metadata
supplement distributed on the GSE203206 GEO series record.

- GEO accession: [GSE203206](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE203206)
- Metadata samples: 47
- Groups: 39 Alzheimer's disease and 8 healthy controls
- Tissue: occipital lobe, primary visual cortex (Brodmann area 17)

The metadata include sample identifiers, diagnosis, demographic information,
neuropathology variables, cognitive measures, mapping rate, and RNA integrity
number (RIN).

The accompanying count matrix contains 46 samples. Sample
`L_5017_OL_RNA_S87` is present in this metadata table but absent from the count
matrix, so it is not included in the differential-expression analysis.

The metadata file is stored unchanged at:

```text
data/metadata/GSE203206/GSE203206_Subramaniam.ADRC_brain.metadata.tsv
```
