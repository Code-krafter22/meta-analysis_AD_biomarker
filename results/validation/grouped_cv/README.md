# Saved validation results

This directory contains public GSE125583 predictions plus aggregate metrics,
coefficients, and ROC images for both cohorts. MSBB participant-level
predictions are intentionally excluded because MSBB is controlled-access.

The grouped-CV files were generated with donor grouping for MSBB, preventing
samples from the same donor from appearing in both training and test folds.
Confidence intervals were produced by donor-level bootstrap for MSBB.
