# Screening sensitivity analyses

Results for the reviewer-requested screening-sensitivity analyses, and the two
prespecified branches they are compared against. Generated by
`scripts/03_meta_analysis/03_meta_analysis_logfc_threshold.R`.

Every run uses the same shared engine as the primary analysis: per-dataset
screening, inverse-variance (1/SE^2) fixed-effect pooling of the five GSE278723
subregions into one study-level estimate, direction-aware Stouffer's Z,
DerSimonian-Laird random effects, MetaVolcanoR, and leave-one-dataset-out with
GSE278723 omitted as a single study. Nothing downstream is reimplemented.

column is informational, not a retention criterion. This matters for Sensitivity
2: under FDR screening GSE67333 contributes no DEGs and GSE203206 contributes
two, so no gene reaches four studies and a >= 4 rule would return 0.

## Sensitivity 1 - no screening: 37 of 37, 21 with I2 < 40%

All 37 pass every significance, direction and leave-one-out gate (max raw pooled
LOO P = 4.99e-02), but 16 exceed I2 = 40%: ADAM33, CHML, COL25A1, KANK2, MAS1,
MRGPRF, NAP1L5, NCALD, NEUROD6, NRN1, OPN3, RGS4, RPH3A, SERPINI1, STAT4,
TCEA3. Removing the screen admits every gene regardless of effect size, so
between-study heterogeneity rises sharply.

## Where genes drop out

At `> 1.0`, 32 of 37 drop, all at the per-dataset screening step. **No gene
reached pooling and then lost significance.** A P-only reference run separates
the two causes:

| Cause | n |
|---|---|
| Failed the magnitude gate (P-significant in >= 4 cohorts, 2-fold in fewer) | 28 |
| Not P-significant in >= 4 cohorts at any threshold | 4 |
| Lost at pooling | 0 |

15 of the 28 clear 2-fold in **no** cohort: CHML, GAD1, HPRT1, HSPB7, ITFG1,
KANK2, KLF15, NCALD, NRN1, OPN3, PIK3R5, SCG2, SERPINI1, TCEA3, TRIM36.

At `> 0.25` nothing drops. Per-gene detail in
[`TableS6c_dropout_stage.csv`](TableS6c_dropout_stage.csv).

Sanity check: the drop at 2-fold is expected, not a bug. Per-arm eligible gene
counts fall from 1,040-7,152 at 0.25 to 117-775 at 1.0, confirming the threshold
was applied and applied on absolute value. No threshold was tuned.

## Consensus criteria

Applied identically to every specification:

1. Present in >= 3 of 5 studies
2. DL random effects: `meta_FDR <= 0.05` and `|meta_logFC| >= 0.3`
3. Direction-aware Stouffer: `FDR <= 0.05`
4. MetaVolcanoR combining method: `FDR <= 0.05`
5. Max raw leave-one-dataset-out `P < 0.05`

I2 < 40% is reported as a separate Panel A column, not folded into the call.

## Known discrepancies, flagged not fixed

1. **Stouffer weights are equal, not sqrt(n)-weighted.** `study_weights` is
   built with `n_total = NA_real_`, so every study gets weight 1. Matched rather
   than changed. If the manuscript claims sample-size weighting, that is wrong.
2. **Minimum-dataset rule.** The engine pools at >= 3 studies; >= 4 is reported
   alongside but is not a retention gate. If the Methods describe a single
   ">= 4" rule it needs rewording.
3. **MetaVolcanoR / ggplot2 4.0.x.** Handled by the existing
   `metavolcano_compat.R` shim, reused unchanged.
4. **Gene symbols.** `CCD102A`/`HSBP7` appear in some older lists; the DE tables
   use the correct `CCDC102A`/`HSPB7`. A correction map is applied to every
   symbol list read here. The 37-gene list is verified complete, including
   COL25A1, by `stopifnot`.

## How to re-run

From the project root:

```r
source("scripts/03_meta_analysis/00_run_all_meta_analyses.R")   # branches 1 and 2
source("scripts/03_meta_analysis/03_meta_analysis_logfc_threshold.R")
```

The FDR branch:

```r
Sys.setenv(META_ANALYSIS_INPUT_FILE = "significant_DEGs_adjusted.csv")
Sys.setenv(META_ANALYSIS_OUTPUT_DIR = file.path(here::here(), "results",
                                                "meta_analysis", "fdr_screened"))
analysis_mode <- "filtered_unadjusted"
source("scripts/03_meta_analysis/run_meta_analysis.R")
```

The sensitivity script aborts if the 0.58 control stops reproducing the primary.
